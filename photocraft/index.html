CommMaker · PhotoCraft embed (proof of concept)

The editor runs in an iframe from vendor/photocraft-web/ (WASM + WebGPU/WebGL2). Requires Chrome/Edge with WebGPU for best results.

COOP / COEP: PhotoCraft does not use SharedArrayBuffer, so isolation headers are not required for the editor alone. If the shell later enables Cross-Origin-Embedder-Policy: require-corp for other features, serve PhotoCraft assets with Cross-Origin-Resource-Policy: same-origin (or cross-origin on a CDN). Use python3 scripts/serve-static.py --coop-coep to test that mode.
